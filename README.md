This report builds an equity portfolio from twenty randomly selected Dhaka Stock Exchange (DSE) stocks, using monthly data from August 2021 to August 2026. The stocks span banks,
financial institutions, insurance, food, pharmaceuticals, telecom, cement and several smaller sectors.

## **The optimization was conducted using Microsoft Excel**
- Matrix Mult
- Solver
- Data Validation
- Covariance
- Basic Excel functions

### Scenarios
- Scenario 1: SS & RF Allowed
- Scenario 2: SS not allowed; RF allowed
- Scenario 3: SS allowed; RF not allowed
- Scenario 4: SS not allowed & RF not allowed

Based on the scenarios, the **Efficient Frontier** was developed by changing the constraints.

Diversification across twenty random stocks gave only modest results. The strongest gains came from selecting a few high-performing stocks, which also made the optimal
portfolios highly concentrated. An investor who needs to stay long-only should weigh the extra return from concentration against the risk of holding so few stocks.
